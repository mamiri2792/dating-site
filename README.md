# ❤️ Dating Site

A mobile-first dating platform where people can create profiles, discover other users, match with mutual likes, and communicate with their matches.

## 🚀 MVP Features

- 👤 Create an account
- 🔐 Secure login
- 📸 Create a dating profile
- 📝 Add bio, interests, location, and preferences
- 🔎 Discover other profiles
- ❤️ Like profiles
- ✕ Pass on profiles
- 💕 Mutual matching
- 💬 Private messaging
- 🚫 Block users
- 🚩 Report users
- ⚙️ Account settings

## 🛠️ Technology

- HTML
- CSS
- JavaScript
- GitHub
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
